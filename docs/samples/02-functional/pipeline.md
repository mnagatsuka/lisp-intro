# データ処理のパイプライン

## 目的

- `remove-if-not`、`mapcar`、`reduce` をつなぐだけで、データ処理が「絞り込む → 変換する → 集計する」の流れとして読めることを見せる。
- 次のToDoアプリ（DDD）につながる、関数型の基本を紹介する。

## ファイル

`samples/02-functional/pipeline/pipeline.lisp` に置く。他言語版は作らない。

## 仕様

- 題材は商品の一覧から、本の合計金額（税込）を求める処理にする。
- 入力：商品のリスト。各商品は名前、カテゴリ、価格（税抜）を持つ。
  - 商品は5〜6件程度で、カテゴリは本とそれ以外が混ざるようにする。
  - データはプロパティリスト（`:name`、`:category`、`:price`）で表す。
- 処理は3段階にする。
  1. `remove-if-not`：カテゴリが本の商品だけに絞り込む。
  2. `mapcar`：各商品を税込価格（税率10%、小数点以下は切り捨て）に変換する。
  3. `reduce`：税込価格を合計する。
- 出力：各段階の結果と最終的な合計金額を表示する。途中の結果を見せて、データが流れる様子が分かるようにする。

## Lisp版の方針

- ループ（`loop`、`dolist` など）と代入は使わない。
- 元のデータを変更せず、各段階で新しいリストを作る。
- 型宣言はしない。
- 3段階を1つの式として読める形にまとめた版も書く。
- 各段階を関数にして、式を読むだけで処理の流れが分かるようにする。

## 補足

- 他言語との比較はしない。
- 高階関数（関数を引数に渡す）の説明は、`lambda` が出てくる範囲にとどめる。

## 実行

- `task pipeline` で実行し、各段階の結果と合計を表示する。
