1. Lispとは

著名人の言葉

Lisp自身をLispで定義した、わずか半ページのコードを「ソフトウェアにおけるマクスウェル方程式」と呼んだ。

アラン・ケイ（計算機科学者） — A Conversation with Alan Kay

Lispを学ぶ価値は、ついにそれを理解した瞬間に得られる、深い悟りのような体験にある。たとえLisp自体をあまり使わなくなったとしても、その体験は一生にわたってあなたをより優れたプログラマにしてくれる。

エリック・S・レイモンド（プログラマ） — How To Become A Hacker

自身が起業したViaweb（ストア構築ツールをLispで開発）の「秘密兵器」はLispだったと語った。

ポール・グレアム（スタートアップ創業者） — Beating the Averages

基本的な考え方

  • Lispは単一の言語ではなく、Common Lisp、Scheme、Clojure、Emacs Lispなどを含む言語ファミリーである。
  • すべてがS式、つまり (operator arg1 arg2 ...) という形のリストで表される。
    • 例: (+ 1 (* 2 3))。コードもデータも同じ構文で書く。
  • コードはデータである（ホモイコニシティ）。
    • プログラムはリストなので、プログラム自身で組み立てたり加工したりできる。
    • この性質が、コードを生成するコードであるマクロを可能にしている。
  • 小さな核を、抽象化で積み上げていく。
    • 少数のプリミティブと lambda があれば、あとはそれらを組み合わせて作れる。
    • Lispの評価器は、Lisp自身で1〜2ページほどで書ける（SICPのメタサーキュラー評価器の発想）。

Lispの歴史

  • 1958 ジョン・マッカーシー（MIT）が、AI研究のためにLispを考案。名前は「LISt Processing」に由来する。Fortranに次いで、現在も使われている最古の高水準言語である。
  • 1960年頃 スティーブ・ラッセルが、マッカーシーの eval をIBM 704上で実装。理論が実際に動くインタプリタとなり、1962年にLisp 1.5マニュアルが公開された。
  • 1970〜80年代 AI研究の中心言語となる（MacLisp、Interlisp、Lispマシンなど）。しかし1980年代後半の「AIの冬」で大きな打撃を受ける。
  • 1975 サスマンとスティールがScheme（MIT）を開発。レキシカルスコープを備えた最小限の設計で、のちにSICPで使われる言語となった。
  • 1984〜94 Common Lispが乱立していた方言を統一し、1994年にANSI規格となった。
  • 1980年代 GNU Emacsが登場。拡張言語としてEmacs Lispが使われている。
  • 2007 リッチ・ヒッキーがClojureを発表。モダンなLispをJVM上で使えるようにした。
  • 現在 主流ではないものの、今も使われ続け、影響力も大きい。
    • 現在も開発が続く処理系: SBCL、Clojure、Racket、Guile、Emacs Lisp。
    • Lispのアイデアは多くの言語に受け継がれている: ガベージコレクション、第一級関数、ラムダ式、REPL、動的型付けなど。
    • JavaScriptは、ブラウザ上でSchemeを動かすという構想から生まれた（ブレンダン・アイク）。詳しくは A Brief History of JavaScript を参照。
    • 採用例: Nubank（Clojure）、Grammarlyの文法エンジン（Common Lisp）、Viaweb（Lisp）。

2. Lispの魅力

シンプルで小さいのに、無限の表現力。言語そのものを、解きたい問題に合わせて育てられる。

1. 統一された構文

  • 書き方は (operator arg ...) の一つだけ。演算子の優先順位も、例外的な構文もない。
  • 括弧によって、プログラムの構造（木構造）がそのまま見える。
(if (> x 0) "pos" "non-pos")   ; 関数呼び出しと同じ形

2. コードはデータ

  • プログラムはリストなので、別のプログラムを調べたり、組み立てたりできる。
'(+ 1 2)         ; 3つの要素を持つただのリスト
(eval '(+ 1 2))  ; => 3

3. マクロ: 言語そのものを拡張できる

  • マクロは実行前にコードを書き換えるので、新しい構文を自分で追加できる。
  • 多くの言語では、新しい構文を足すには言語仕様の更新が必要になる。
(defmacro unless (test &body body)
  `(if ,test nil (progn ,@body)))

4. 値としての関数とクロージャ

  • 関数は、ほかの値と同じように渡したり、返したり、保存したりできる。
  • クロージャは周囲の環境を保持する。これだけで、オブジェクトやカウンタ、ストリームまで作れる。
(map (lambda (x) (* x x)) '(1 2 3))  ; => (1 4 9)

5. REPLによる対話的な開発

  • 動いているプログラムの中で、コードを書き、実行し、変更する。再起動の手間がない。
  • Emacsのカスタマイズも同じスタイルで、動いているエディタを内側から書き換えていく。

3. Lispの現在

古典的AI

  • 記号AI（エキスパートシステム、プランニング、自然言語処理など。例: SHRDLU）の主要言語だった。
  • シンボルとリストは、知識やルールの表現と相性が良い。
  • 常識知識ベースを構築する長期プロジェクトCycも、この流れから生まれた。
  • AIの冬と、統計的手法やニューラルネットワークの台頭により、勢いを失った。
  • 今あらためて注目したい理由: 記号的推論が、LLMを補う技術として見直されつつある。

ツール

  • Emacs: Emacs Lispを使えば、動作中のエディタをその場で書き換えられる。Org-modeやMagitも、この上に作られている。
  • CAD: AutoCADにはAutoLISPが組み込まれ、図面作業の自動化に使われている。図面は入れ子構造のデータなので、Lispとの相性が良い。

システム

  • 表現力が求められるニッチな領域を中心に、今もLispで動くプロダクトがある。
  • Nubank（デジタルバンク）は、JVM上のClojureを使っている。
  • Grammarly（文法エンジン）とITA Software（航空券検索。のちのGoogle Flights）は、Common Lispを使っている。
  • Rigettiの量子コンピュータ向けコンパイラQuilcは、Common Lispで書かれている。
